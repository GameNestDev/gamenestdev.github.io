# GAME NEST

GAME NEST 팀 홈페이지 (https://gamenestdev.github.io/)

정적 사이트입니다. `index.html`을 수정하면 GitHub Pages에 자동으로 반영됩니다.

- 언어: 한국어/영어/일본어. 한국어는 HTML에 그대로 쓰고, 영어·일본어 문구는 각 페이지 하단 `window.I18N`에 있습니다. 전환 로직은 `lang.js`이며 `?lang=en`처럼 주소로도 언어를 고를 수 있습니다.
- 개인정보처리방침: `privacy/index.html` → https://gamenestdev.github.io/privacy/
